# 需求单：借鉴 Green Frog 架构的工程纪律改进

- 日期：2026-10-04
- 背景：对流行插件 Green Frog（`redleafnew/zotero-updateifsE`）的架构调研结论。值得抄的是**工程纪律层**，它的脚手架包袱（toolkit 重依赖、scaffold 构建链、示例式命名）明确不搬。
- 范围：以下 6 项**全部要做**，每项独立可验证。

## 红线（所有实现必须遵守）

1. **保持零第三方运行时依赖**：不引入 `zotero-plugin-toolkit` 及任何运行时 npm 包（构建期 dev 依赖除外）。
2. **直接在 `main` 上开发**，不走 feature 分支（本仓库约定）。
3. 兼容 **Zotero 9 及更高版本**。
4. 完工标准：`npx tsc --noEmit` 零报错、`npm run build` 正常、`npm test` 全过；本地验证通过后再一次性推送。

---

## 需求 1：JS 侧 Fluent 国际化

- **现状问题**：`src/panel.ts`、`addon/content/preferences.js` 里有硬编码中文（如取不到集合列表时的提示）。英文用户会看到中文。
- **改动点**：
  - 新增 `src/utils/locale.ts`，封装 `initLocale()` / `getString(key, args?)`（参考 Green Frog 用 `Localization` 实例供 JS 调用的模式）。
  - 把 panel.ts、preferences.js 里的硬编码中文全部替换为 `getString` 调用；`addon/locale/zh-CN/skill-task.ftl`（及 en-US，如有）补齐对应 key。
- **验收**：Zotero 界面语言切为英文时，面板与设置页无中文残留；中文环境下文案与原来一致。

## 需求 2：生产环境日志收敛

- **现状问题**：`src/utils.ts` 的 `log()` 永远向控制台输出，生产包刷屏。
- **改动点**：
  - `scripts/build.mjs` 用 esbuild `define` 注入环境标识（如 `__env__`；若已有等价机制则复用）。
  - `log()` 在生产环境下关闭 info/debug 级别的 console 输出；错误日志保留。
- **验收**：生产构建的 XPI 装入 Zotero 后，控制台无 info/debug 日志；发生错误时仍有可定位的错误输出。

## 需求 3：启动时等待 Zotero 就绪

- **现状问题**：`core.ts` 的 `startup()` 直接跑 store 加载，未等待 Zotero 完全就绪，冷启动时可能踩空。
- **改动点**：`startup()` 开头 `await Promise.all([Zotero.initializationPromise, Zotero.unlockPromise, Zotero.uiReadyPromise])`（先确认这些 Promise 在 Zotero 9 上可用；若不可用，做版本兼容处理，不硬编码假设）。
- **验收**：Zotero 冷启动与重启后插件功能正常，无因启动时序导致的空数据/异常。

## 需求 4：长驻回调存活守卫

- **现状问题**：notifier 回调、任务租约 timer 不检查插件是否已卸载，极端时序下可能操作已释放资源。
- **改动点**：
  - `core.ts` 加 `alive` 标志，`shutdown()` 时置为 false。
  - notifier 回调、租约 timer、快捷键回调入口先查 `alive`：已卸载则自注销监听/清除 timer 并直接返回。
- **验收**：在附加组件管理器中禁用/卸载插件后，控制台无报错、无残留 timer 活动。

## 需求 5：方法级统一日志装饰器

- **现状问题**：各处手写 log 格式不一，排障时难定位。
- **改动点**：
  - 新增 `src/utils/trace.ts`，提供 `@traced` 装饰器：自动记录类名+方法名的进入日志与异常日志（异常带堆栈）。
  - 应用到关键方法：store 读写、MCP claim/submit、任务生成器扫描。
- **验收**：关键路径日志格式统一；抛异常时能从日志直接定位到类和方法。

## 需求 6：快捷键可配置化

- **现状问题**：`Ctrl+Shift+J`（macOS `⌘+Shift+J`）写死在代码里。
- **改动点**：
  - `src/prefs.ts` 加偏好键：快捷键启用开关 + 按键组合（建议 Mac/Win 分开存）。
  - 设置页（原生 XUL preferences.xhtml）加对应配置项。
  - `ui.ts` 快捷键注册改为读取偏好；修改后实时生效（或提示重启，以实现简单为准）。
- **验收**：设置页可修改快捷键并生效；与 Zotero 或其他插件快捷键冲突时有可见提示（若实现成本高，至少保证不静默失效）。

## 明确不做（不要碰）

- `zotero-plugin-toolkit` 及任何运行时第三方依赖（红线）。
- windingwind scaffold 构建链：继续用现有手写 esbuild 脚本。
- `XxxExampleFactory` 之类示例命名：保持现有按业务域的命名。
- Beta 更新通道：当前用不上，不做。
- hooks 纯调度重构：当前 `PluginCore.startup` 规模可接受，重构收益小，不做。

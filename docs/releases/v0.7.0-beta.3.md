# v0.7.0-beta.3 · 双开关网络访问与外网 OAuth

本次 beta 使用独立的 `23123` 本机／局域网端口与 `23124` 外网 OAuth 端口，保留通用内建笔记完成判定及下拉框修复。

## 网络访问

MCP 服务开启时，两项开关按以下规则生效；默认均关闭。

| 允许远程访问 | 启用 OAuth 授权 | 23123 | 23124 |
|---|---|---|---|
| 关闭 | 关闭 | 仅本机回环，免鉴权 | 关闭 |
| 关闭 | 开启 | 仅本机回环，免鉴权 | 关闭 |
| 开启 | 关闭 | 本机／局域网，免鉴权 | 关闭 |
| 开启 | 开启 | 本机／局域网，免鉴权 | 外网 OAuth |

- 本机地址：`http://127.0.0.1:23123/skilltask/mcp`；局域网客户端将回环地址替换为 Zotero 所在电脑的私网 IP。
- 外网须填写 HTTPS 公开地址，并将 HTTPS 代理指向 `http://127.0.0.1:23124`。`23124` 对包括本机代理在内的所有来源执行 OAuth 鉴权；免鉴权的 `23123` 不应作为公网代理目标。
- OAuth 使用授权码、S256 PKCE 与 Zotero 本机确认，支持刷新令牌轮换和撤销全部授权。关闭服务、修改访问模式／公开地址或重启 Zotero 后需要重新授权。
- 不占用、不修改 Zotero 的 `23119`；移除旧的插件端口 `23121`。端口冲突时显示错误，不自动改用其他端口。

## 安装与验证

下载 `zotero-skill-task-mcp-0.7.0-beta.3.xpi`，在 Zotero 的插件管理器中选择从文件安装，然后重启 Zotero。插件支持 Zotero 9–10。

从旧 beta 升级后，将 MCP 客户端地址改为 `23123`；旧静态访问令牌不再使用。需要远程访问时，按上表重新设置开关，外网部署步骤见[网络访问与 OAuth 文档](https://github.com/Yyu-ang/zotero-skill-task-mcp/blob/fix/network-access-oauth/docs/network-access.md)。

# 0.7.0-beta.1 · 内建笔记通用完成判定

本次 beta 为技能组增加可选的已有笔记完成规则。插件在派发侧识别文献已有结果，减少重复领取与重复写入。规则默认关闭，可用于任何以 Zotero 内建笔记为交付物的技能。

## 新增功能

- 按技能组配置笔记标签、标题、可见文本标记、全部／任一条件、排除条件和最少内容长度。
- 所有条件在同一篇直接子笔记上判断；只读取个人文库中的非删除笔记。
- 编辑界面提供只读预览，可检查当前选中的前 20 篇文献并打开匹配笔记。
- 扫描、领取前和提交前共用规则判断；笔记新增、修改、删除、移动及标签变化会触发重判。
- 命中的结果显示为“已完成／已有笔记”，实际提交次数为 0，并与本次 AI 提交活动分开统计。
- `skilltask_inject_skill` 支持结构化 `completionRule`；无需改变或解析 SKILL.md。

## 任务一致性

- 扫描、领取、提交、取消和归还在同一技能组与文献内顺序执行。
- 已领取任务保留领取时的规则与交付格式；后台扫描不接管租约。
- 提交前发现合格笔记时复用其引用，不再创建笔记。
- 读取异常会显示判定错误并阻止派发，不把异常当作“没有完成”。
- 仅由已有笔记规则认定完成的任务会在结果失效后重新开放；用户取消的任务和实际提交完成的任务不会自动重做。
- 关闭规则保留已经识别的完成记录；旧技能组缺少配置时保持原有行为。

## 安装与使用

1. 下载本发布中的 `zotero-skill-task-mcp-0.7.0-beta.1.xpi`，通过 Zotero 插件管理界面的“从文件安装插件”安装。
2. 编辑技能组，将交付物设为“内建笔记”或“Markdown → 笔记”。
3. 启用“已有笔记完成判定”，设置条件，先对选中文献预览。
4. 保存后重新扫描技能组。

详细语义和 MCP 示例见 [内建笔记完成判定说明](https://github.com/Yyu-ang/zotero-skill-task-mcp/blob/v0.7.0-beta.1/docs/note-completion-rules.md)。
